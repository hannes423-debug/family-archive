# People who appear in published material but are not (yet) in the tree.
#
# WHY THIS FILE EXISTS
# --------------------
# verify_public.py cross-checks everything committed against the given names of
# living people, so that a name cannot reach the public repo by some path the
# redaction does not cover. Names repeat across generations, so that check has
# to know which repetitions are safe.
#
# It learns most of them from the tree itself: a name also borne by someone the
# tree records as deceased identifies nobody new. But a photograph can be of
# somebody who is not in the tree at all — a great-great-grandmother whose
# gravestone survives but whose record has not been entered yet — and that name
# has nowhere to be declared. This is that place.
#
# Every line is a claim that this person has died, with the evidence for it.
# Do not add a living person here to silence a warning; that is precisely the
# check this file is weakening, and the whole point is that the weakening is
# written down where it can be read.
#
# Format:  Full name | dates | evidence
#
# "dates" is either a death year at least 25 years past (e.g. 1875-1952, or
# d1952), or a birth year at least 100 years past (e.g. b~1890). The second form
# is the archive's own presumed-death rule, and exists for people who are known
# only as somebody's parent — no record of their death, but no possibility of
# their being alive either.
#
# Blank lines and lines starting with # are ignored.
